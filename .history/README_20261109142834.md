# A.R.I.S.A.

### Autonomous Real-time Intelligence & System Agent

A local-first, privacy-focused modular AI system engineered for local execution on Apple Silicon/macOS, designed to scale from software core to custom physical hardware interfaces.

---

## Architecture

- **`core/`**: Central nervous system (local LLM inference engine via Ollama & audio ingestion via Faster-Whisper).
- **`agents/`**: Specialized sub-worker loops for task automation and domain analytics.
- **`tools/`**: Standalone utility scripts, database connectors, and integrations.
- **`ui/`**: Local interface elements and web dashboard components.
- **`docs/`**: System architecture notes, specifications, and project logs.
